Outcraft Cart Recovery

Send abandoned eCommerce carts to Outcraft, whose AI agents call, text and email the shopper to help them finish the order. Confirmed orders are sent too, so outreach stops as soon as the shopper pays.

Abandoned carts

Every 15 minutes, website carts that have a phone number and have not changed for 60 minutes (configurable) are sent to Outcraft once, with a link that reopens the cart.

Confirmed orders

When a website order is confirmed, it is sent with the same id as its cart, so Outcraft stops contacting that shopper and can report recovered revenue.

Checkout is never slowed down

Nothing is sent from the checkout itself. A scheduled action sends events in the background with a short timeout and retries failed sends on its next run.

Requirements

  • An Outcraft account. This module only sends events; the calls, SMS and emails are made by Outcraft, a separate service. Without an account the module does nothing.
  • Odoo 20.0 with the eCommerce app (website_sale).
  • Odoo on-premise or Odoo.sh. Like every third-party module that contains Python code, it cannot be installed on Odoo Online (SaaS).

Setup

  1. In Outcraft, create an abandoned-checkout campaign with a Custom API trigger and copy its URL, shown under Send events to this endpoint. It looks like https://app.outcraft.ai/api/v1/trigger/<token>.
  2. Install this module.
  3. Go to Website > Configuration > Settings, find Send carts to Outcraft, tick the box, paste the trigger URL and save. The same steps are shown right there in the settings.
  4. Click Send test event. Outcraft receives a sample cart followed by its completion, so the connection shows up in Outcraft and no one is contacted.
  5. Optionally change Abandoned after (default 60 minutes).

Nothing is sent until the box is ticked and a URL is set. Carts and orders from before that moment are never sent. Untick the box to stop sending at any time.

Each event is an HTTPS POST of JSON to the trigger URL you configured. Nothing else is sent, and no data is sent anywhere else.
